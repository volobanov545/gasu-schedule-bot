# Запуск расписания через GitHub Actions

Сервер и постоянно включённый компьютер не нужны. Целевая схема запускает получение
публичного расписания в российском CI, а GitHub отправляет карточку на завтра в тему
Telegram. База данных, входящие сообщения, участники, файлы и AI не используются.

## Что добавить в GitHub

Открой репозиторий → **Settings → Secrets and variables → Actions → New repository
secret** и создай четыре секрета:

| Secret | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен отдельного бота из BotFather |
| `TARGET_CHAT_ID` | отрицательный технический ID Telegram-группы |
| `SCHEDULE_TOPIC_ID` | положительный ID темы «Расписание» |
| `SPBGASU_GROUP_ID` | обозначение/ID учебной группы, которое принимает публичное расписание |

Не присылай токен в чат и не добавляй его в файлы репозитория. Бот должен быть добавлен
в группу и иметь право отправлять сообщения в нужную тему; администратором ему быть не
обязательно.

## Первый запуск

1. Открой вкладку **Actions**.
2. Выбери **Publish tomorrow's schedule**.
3. Нажми **Run workflow**.
4. Проверь, что в теме появилась одна карточка на завтра.

Автоматический cron временно выключен: реальный GitHub-hosted запуск 11.09.2026 не смог
подключиться к `rasp.spbgasu.ru` и завершился до обращения к Telegram. Ручной запуск
остаётся доступен для диагностики. Для выпуска без VPS нужен CI-мост: российский
GitVerse runner получает публичное расписание, а GitHub Actions отправляет уже готовую
карточку в Telegram. После проверки моста ежедневный запуск следует включить на 20:30
по Москве. Повторный ручной запуск отправит дубликат, если источник станет доступен.

## Настройка CI-моста

1. Создай приватный репозиторий GitVerse и загрузи в него этот код.
2. В GitHub создай fine-grained personal access token только для репозитория
   `gasu-schedule-bot`, сроком на 90 дней и с единственным изменённым разрешением
   **Actions: Read and write**.
3. В GitVerse открой **Настройки → Секреты и переменные** и добавь секрет
   `BRIDGE_GH_TOKEN` со значением этого токена.
4. Запусти вручную workflow **Fetch SPbGASU schedule and hand off to GitHub**.
5. Проверь, что GitVerse получил расписание, GitHub workflow
   **Send schedule received from GitVerse** завершился успешно, а в Telegram появилась
   одна карточка.

GitVerse не получает токен Telegram. GitHub не получает доступ к сайту СПбГАСУ:
между площадками передаётся только готовый текст общедоступного расписания без ФИО
преподавателей. Автозапуск GitVerse установлен на 20:30 по Москве.

Если компьютер выключен, публикация всё равно выполняется на GitHub. Если GitHub Actions,
Telegram или публичный сайт СПбГАСУ недоступен, конкретный запуск завершится ошибкой и
ничего не выдумает из старых данных.
